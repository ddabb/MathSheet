# 口算题卡 · 1.0.1 优化计划：错题闭环打磨与打印直连

> 承接《口算题卡开发计划_买断制小学口算打印生成器.md》（v1.0.0 立项）。
> 版本基调：v1.0.0 已交付构造式生成引擎、年级题型、错题本、在线作答、A/B/C/D 卷与导出。1.0.1 聚焦「把已落地功能打磨到顺手」——错题重练闭环的体验收口、打印直连落地、数据可迁移，让买断价值在每天一页的真实使用里被感知。

## 1. 背景与定位

v1.0.0 把错题本、在线作答、历史卷库都做出来了，但「生成→批改→重练」这条留存主链还有毛刺：错题重练卷混编比例固定、速录批改的边界提示不够、打印仍走「导出 PDF 再手动打印」两步。1.0.1 把闭环和打印直连做扎实，并把换机迁移这个高痛点击穿。

核心原则：**离线、买断、不联网不变；全部优化为本地引擎与打印管线增强。**

## 2. 优化项清单

| 编号 | 模块 | 现状（v1.0.0） | 1.0.1 优化 | 验收 |
|---|---|---|---|---|
| M1 | 错题重练闭环 | 错题:同类新题 = 1:2 混编，仅固定比例 | 混编比例可调（1:1 / 1:2 / 1:3）；「仅错题」与「错题+同类」两种模式；重练卷标注来源卷日期 | 从错题本生成重练卷，比例切换生效，来源可追溯 |
| M2 | 速录批改 | 对照答案页点选错题速录，其余记对 | 速录增加「整卷全对」一键、单题撤销；空批卷提醒先批改再重练；速录与在线作答判分结果合并去重 | 速录 100 题 < 30 秒完成，结果入库与在线一致 |
| M3 | 在线作答体验 | 练习即时判分 / 测验静默判分已落地 | 限时挑战模式前移（倒计时 + 交卷计时展示）；练习模式错停时展示正确答案停留时长可调；数字键盘支持小数点与负号 | 限时测验交卷出成绩正确，键盘覆盖小数/负数题型 |
| M4 | 打印直连 | P0 查证项，未引入 | 落地 @ohos.print：当前预览卷经 fd:// 直接拉起系统打印预览，跳过「存 PDF」中间步；保留「存文件/分享」并存 | 三款打印机实测直连出图，题头/答案页布局正确 |
| M5 | A/B/C/D 卷 | 多套同构卷已支持 | 各套答案页独立分页（不混在同末页）；卷头标注 A/B/C/D；教师批量打印提示 | 4 套卷答案各自独立、不串 |
| M6 | 数据备份恢复 | 仅本地列表，换机丢失 | 卷库 + 错题本 + 打卡导出为单文件 / 导入恢复（本地文件，无需云）；导出含版本号与校验 | 导出→卸载→重装→导入，数据完整恢复 |
| M7 | 生成引擎鲁棒 | 拒绝采样 64 次上限、可行域不足提示 | 可行域自动放宽提示文案标准化（如「3 的口诀仅 9 题，已放行重复」）；连加连减/带括号题型边界值回归 | 极值参数下不崩溃、提示友好 |
| M8 | 高年级扩展前移 | P1 计划 | 四五年级（多位数乘除、运算律/简便运算专项）题型前移进 1.0.1；竖式题版面（加/减/乘）同步 | 四五年级题型生成正确，竖式排版对齐 |

## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| @ohos.print 设备兼容 | 真机 + 3 款打印机回归；降级路径保留「存 PDF 分享打印」 |
| 备份文件被误改 | 导入校验版本号与完整性，损坏文件拒绝导入并提示 |
| 高年级题型扩大测试面 | 题型用确定性纯函数，补 TDD 用例覆盖新题型边界 |

## 4. 非目标（明确不做）

- 不做拍照批改 / OCR 判卷
- 不做教学内容 / 视频 / 课程推荐
- 不做账号 / 云同步 / 排行榜 / 社区
- 不做订阅 / 广告 / 内购解锁

## 5. 验收总览

- 错题闭环：重练比例可调、速录高效、来源可追溯
- 打印：直连落地 + 答案独立分页
- 数据：换机可备份恢复
- 题型：覆盖至四五年级 + 竖式
- 全链路离线、买断说明与版本号正确
